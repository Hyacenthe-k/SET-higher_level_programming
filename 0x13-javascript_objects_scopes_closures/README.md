# 0x13. JavaScript - Objects, Scopes and Closures (Part 2)

This directory contains advanced JavaScript exercises focusing on higher-order array methods, closure state preservation, base conversion, object manipulation, and File System operations.

## Tasks Summary

| File | Description |
| --- | --- |
| `7-occurrences.js` | Exports `nbOccurences(list, searchElement)` which counts how many times `searchElement` appears in `list`. |
| `8-esrever.js` | Exports `esrever(list)` which returns a reversed copy of `list` without using built-in `.reverse()`. |
| `9-logme.js` | Exports `logMe(item)` which tracks print calls using closure variable scope and outputs `<index>: <item>`. |
| `10-converter.js` | Exports `converter(base)` returning a function that converts numbers into the specified `base` without local variable declarations. |
| `100-map.js` | Imports `list` from `100-data.js` and outputs a new array where each item is multiplied by its index using `.map()`. |
| `101-sorted.js` | Imports `dict` from `101-data.js` and inverts occurrences and user IDs into an occurrence-keyed array object. |
| `102-concat.js` | Takes three CLI arguments (source File A, source File B, destination File C) and concatenates File A and B into File C. |
