# Higher Level Programming - JavaScript Web Scraping

This project contains a series of JavaScript tasks focusing on file input/output and web scraping using Node.js, the `request` module, and the standard API endpoints.

## Requirements
- Allowed editors: `vi`, `vim`, `emacs`
- Interpreted on Ubuntu 20.04 LTS using Node.js (version 14.x)
- All files end with a new line
- The first line of all files is exactly `#!/usr/bin/node`
- Code is semistandard compliant
- All files are executable
